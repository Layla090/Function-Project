# Function-Project
I made a function game called “Just Graph." The name is a parody of the popular motion-based video game Just Dance, replacing the dancing and rhythm aspect with matching functions quickly and accurately. In this game, a graph is shown for a few seconds, then the camera turns on and the player has to recreate the graph using their arms. The game then captures the pose and judges how well the player matched the function.

I chose this idea for two reasons. First, my friends have coded other versions of this gameplay before. They also used MediaPipe, a tracking and detection API, to create a variety of programs. Secondly, in math class we used our arms to model equations which gave me this idea that functions can be found everywhere in the real world, even on our bodies.

Moreover, I used MediaPipe, numpy, and streamlit for the tracking, graphing, and camera. I used Python and this was my first time really working with it.
I struggled with the Python script especially because this was my first time using the language, so basic structure and debugging took time. I also had to figure out how to manage different parts of the app, like switching between the graph, camera, and scoring screens, which was confusing at first.
